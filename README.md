# test

A small space to experiment: a clean page with animated “testing” text and a choice of light or dark mode.

## Features

- **Text reveal** — scrambled characters settle into “testing” when you open the page.
- **Comfortable themes** — starts with your system theme and remembers your light/dark choice.
- **Update checks** — check for a newer version and reload once it’s available on the live site.
- **Accessible by design** — keyboard-friendly controls, a stable heading for screen readers, and no text animation when reduced motion is enabled.

[View the latest release](https://github.com/jakariatanjim-svg/test/releases/latest)

## Requirements

Use a current version of Chrome, Edge, Firefox or Safari, with JavaScript enabled. An internet connection is needed to check for updates.

## Privacy

Your theme preference and the last update-check result are saved in your browser. Automatic update checks reuse results for two minutes; manual checks contact GitHub immediately. GitHub receives ordinary connection information, such as your IP address. The app has no analytics, accounts or uploaded user content.
