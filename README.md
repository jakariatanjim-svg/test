# test

A small space to experiment: a clean page with animated “testing” text and a choice of light or dark mode.

## Features

- **Text reveal** — scrambled characters settle into “testing” when you open the page.
- **Comfortable themes** — starts with your system theme and remembers your light/dark choice.
- **Accessible by design** — keyboard-friendly controls, a stable heading for screen readers, and no text animation when reduced motion is enabled.

[View the latest release](https://github.com/jakariatanjim-svg/test/releases/latest)

## Requirements

Use a current version of Chrome, Edge, Firefox or Safari, with JavaScript enabled. An internet connection is needed to open the live site.

## Privacy

Only your light/dark theme preference is saved in your browser. The page makes no update-check requests and has no analytics, accounts or uploaded user content.
